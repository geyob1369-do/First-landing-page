# Landing Page

A simple landing page built with HTML and CSS as part of my journey to becoming a full-stack developer.

## About the Project

This project is a practice landing page inspired by common website layouts. It helped me practice structuring a webpage with HTML and styling it with CSS.

## Features

- Navigation bar with links
- Hero section with a heading, text, image, and sign-up button
- Information section with four content boxes
- Quote section
- Footer with a call-to-action message and sign-up button

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Practiced

- CSS selectors and combinators
- Flexbox layout
- The CSS box model
- Margins and padding
- Background colors, borders, and border
